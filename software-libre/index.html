Filosofía de software libre

Próximamente: principios, transparencia de licencias, reproducibilidad, interoperabilidad y modelo de sostenibilidad.

La iniciativa se apoya en la cultura del software libre y la transparencia. Las licencias de cada proyecto se publicarán tras la auditoría correspondiente; ninguna licencia se asume sin verificarla.

Stack tecnológico

Tecnologías que usamos

Estas son las tecnologías que utilizamos en Expanse, Vuigram, RSS2 y ChatLand. Priorizamos estándares abiertos, software libre y herramientas que podamos ejecutar y mantener por nuestra cuenta.

Infraestructura y despliegue

  • Docker Contenedores y despliegue
  • Linux Sistema base de servidores
  • Nginx Servidor web y proxy inverso
  • Traefik Proxy Enrutado y certificados TLS
  • Prometheus Métricas y monitorización
  • Grafana Paneles y observabilidad

Backend

  • Node.js Servicios y aplicaciones web
  • Go APIs y servicios de alto rendimiento
  • Python Procesamiento de datos y NLP
  • Kotlin Aplicación Android
  • Flask Workers y servicios Python
  • XMPP Mensajería federada en ChatLand
  • Lua Módulos de Prosody en ChatLand

Frontend

  • TypeScript Aplicaciones tipadas
  • React Interfaces de usuario
  • Next.js Aplicaciones web full-stack
  • Tailwind CSS Sistema de estilos
  • Vite Build y desarrollo frontend

Datos y mensajería

  • PostgreSQL Base de datos relacional
  • MongoDB Base de datos de Expanse
  • Redis Caché, sesiones y presencia
  • NATS Mensajería entre servicios
  • MinIO Almacenamiento compatible con S3

3D y móvil

  • Godot Engine Sala 3D de ChatLand
  • Android Cliente móvil
  • Jetpack Compose UI nativa de Android
  • WebRTC Voz y vídeo en tiempo real

Herramientas

  • Git Control de versiones
  • GitHub Repositorios y CI/CD
  • pnpm Gestión de paquetes en Expanse

Las marcas y logotipos pertenecen a sus respectivos titulares y se utilizan únicamente para identificar las tecnologías.
