aten-ia

Asistente de IA con memoria local

Conversa con un modelo que se ejecuta en tu CPU y busca en tus propios documentos. La memoria se conserva entre sesiones.

  • Versión 0.3.12
  • Apache 2.0
  • Rust · llama.cpp
Documentación en GitHub

Inferencia en CPU

Elige un modelo GGUF y ejecútalo desde la terminal con llama.cpp. Una vez descargado el modelo, puedes conversar sin conexión.

Memoria y documentos

Importa PDF, EPUB, Markdown, páginas web o fuentes RSS. El agente guarda conversaciones y documentos en archivos locales y recupera pasajes mediante búsqueda por palabras clave.

Integración

Una API HTTP compatible con OpenAI permite consultar los modelos y transmitir respuestas a clientes como OpenCode o Continue para VS Code.
