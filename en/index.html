Projects

Our applications

Six applications for working with containers, news, commerce, messaging, terminals and local AI.

  • Docker Compose

    Expanse

    Design a stack on the canvas, review its YAML and deploy the services. Available as a web app and a native Windows edition.

  • Telegram commerce

    Kagosiru

    The successor to Vuigram connects a storefront, bot and merchant dashboard. Manage orders, stock, coupons and invoices from one account.

  • International news

    RSS2

    Read RSS and Atom sources in Spanish, find related stories and save articles. Deploy the web stack or install it directly on Windows 11.

  • Spatial messaging

    ChatLand

    Join an XMPP room on Android, talk over voice and explore the shared space with your avatar. Functional lab build.

  • Terminal and desktop

    ssh05

    Organise OpenSSH hosts, open terminals in tabs and reconnect to your sessions when you return to the desktop.

  • Local AI

    aten-ia

    Run a language model on your CPU and search your own documents. Conversation memory persists between sessions.
