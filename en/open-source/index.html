Open source

Licences and open standards

We choose formats that work with other tools, including OpenSSH, XMPP, RSS and Docker Compose.

Each project has its own terms of use. ssh05 is released under MIT and aten-ia under Apache 2.0. Check the licence for the version you plan to use.

Technology stack

Technologies we use

These are the technologies we use across Expanse, Kagorisu, RSS2, ChatLand, ssh05 and aten-ia. We prioritise open standards, free software and tools we can run and maintain ourselves.

Infrastructure and deployment

  • Docker Containers and deployment
  • Linux Base server system
  • Nginx Web server and reverse proxy
  • Traefik Proxy Routing and TLS certificates
  • Prometheus Metrics and monitoring
  • Grafana Dashboards and observability

Backend

  • Node.js Services and web applications
  • Go High-performance APIs and services
  • Python Data processing and NLP
  • Kotlin Android application
  • Flask Python workers and services
  • XMPP Federated messaging in ChatLand
  • Lua Prosody modules in ChatLand

Frontend

  • TypeScript Typed applications
  • React User interfaces
  • Next.js Full-stack web applications
  • Tailwind CSS Styling system
  • Vite Frontend build and dev server

Data and messaging

  • PostgreSQL Relational database
  • MongoDB Expanse database
  • Redis Cache, sessions and presence
  • NATS Service messaging
  • MinIO S3-compatible storage

3D and mobile

  • Godot Engine ChatLand 3D room
  • Android Mobile client
  • Jetpack Compose Native Android UI
  • WebRTC Real-time voice and video

Tooling

  • Git Version control
  • GitHub Repositories and CI/CD
  • pnpm Package manager in Expanse
