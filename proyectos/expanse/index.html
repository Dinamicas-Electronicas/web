Expanse

El IDE visual para Docker Compose

Diseña infraestructuras de contenedores sobre un lienzo visual, despliégalas con un clic y síguelas en tiempo real.

De la arquitectura visual al despliegue, sin escribir YAML a mano. Expanse genera el Compose y habla directamente con Docker Engine.

Qué es

Diseñar, desplegar y operar sin tocar YAML

Expanse es una aplicación web autoalojada para diseñar, desplegar y operar stacks de Docker Compose. Arrastra servicios al lienzo, conéctalos, configura recursos y deja que la aplicación valide puertos, genere el YAML y ejecute Docker Compose contra el motor del host.

  • Editor

    Lienzo visual

    Arrastra servicios, conecta dependencias y ordena la arquitectura con auto-layout sobre React Flow y ELK.js.

  • Biblioteca

    142 plantillas

    14 categorías: bases de datos, IA, automatización, CMS, monitorización, redes, mensajería, medios y más.

  • Stacks

    25 stacks y 5 variantes HA

    Configuraciones completas listas para desplegar, con opciones de alta disponibilidad para bases de datos y servicios.

  • Despliegue

    Docker real, un clic

    Valida puertos, genera el compose y ejecuta docker compose up contra el Docker Engine del host.

  • Observabilidad

    Estado, métricas y logs

    Consulta el estado de los servicios, CPU, memoria y logs en vivo desde el panel de ejecución.

  • Terminal

    Shell por contenedor

    Abre una terminal interactiva con xterm.js sin salir del navegador.

  • Alta disponibilidad

    HAProxy, réplicas y PgBouncer

    Balanceo, réplicas de Compose y pooling de conexiones generados desde el panel de HA.

  • Seguridad

    Cuentas y sesiones

    JWT en cookie httpOnly, bcrypt, MFA TOTP opcional, sesiones revocables y auditoría de operaciones sensibles.

  • Operación

    Cuotas y límites

    Cuotas de proyectos y servicios por cuenta, límites de CPU y memoria por contenedor y runbook de operaciones.

  • Colaboración

    Compartir y exportar

    Enlaces de solo lectura con caducidad configurable y exportación del lienzo a PNG.

Flujo de trabajo

De la idea al contenedor en tres pasos

  1. Diseña

    Elige servicios de la biblioteca, arrástralos al lienzo y conecta dependencias. Ajusta puertos, variables, volúmenes y recursos.

  2. Despliega

    Pulsa Run, elige alta disponibilidad si la necesitas y deja que Expanse valide conflictos de puertos y genere el Compose.

  3. Monitoriza

    Sigue el estado, las métricas y los logs; entra en cualquier contenedor desde la terminal integrada.

Empezar

Ejecutar Expanse en local

Necesitas Docker Engine 20.10+ con Compose v2 y buildx, pnpm 12 para generar los secretos, 4 GB de RAM y el puerto 4000 libre. MongoDB se incluye en el stack.

git clone https://github.com/Dinamicas-Electronicas/expanse.git
cd expanse
pnpm generate-secrets
docker compose up -d --build

Abre http://localhost:4000. Expanse necesita acceso al socket de Docker para gestionar los contenedores del host.

Firecracker en el motor de ejecución

El siguiente salto de Expanse es añadir Firecracker como motor de ejecución: en lugar de compartir el kernel del host, cada stack se ejecutará en su propia microVM. Docker Compose y las imágenes OCI se mantienen igual; cambia la forma de ejecutarlas, no la forma de diseñarlas.

  • Aislamiento

    MicroVM reales

    Cada stack corre con su propio kernel y sus propios límites. Un fallo, una dependencia rota o un contenedor comprometido no alcanza al host ni a los demás proyectos.

  • Seguridad

    Pensado para multiusuario

    Límites de CPU y memoria por microVM, útil para espacios de equipo, demos, formación y pruebas de plantillas de terceros con más garantías.

  • Rendimiento

    Arranque en milisegundos

    Firecracker está diseñado para cargas efímeras y arranca en una fracción de segundo. La diferencia se nota al crear, reiniciar y destruir entornos desde el lienzo.

  • Recursos

    Más stacks por servidor

    Sin hypervisor pesado ni sistema operativo completo por entorno: menos memoria y CPU desperdiciadas, más proyectos conviviendo en la misma máquina.

  • Compatibilidad

    Sin cambiar el flujo

    Las imágenes, los Dockerfiles y los ficheros Compose siguen siendo válidos. La migración es transparente desde la interfaz de Expanse.

  • Marketplace

    Probar sin miedo

    Ejecutar stacks de la comunidad en microVM aisladas reduce el riesgo de abrir una plantilla desconocida antes de confiar en ella.

Aplicación de escritorio

Expanse nació como aplicación web autoalojada y seguirá siéndolo. La app de escritorio añadirá una vía directa para quien prefiere no administrar un servidor: instalar, abrir y desplegar.

  • Experiencia

    Nativa, no una pestaña

    Ventana propia, menús, atajos de teclado y bandeja del sistema. El lienzo deja de depender del navegador y del estado de una pestaña.

  • Docker local

    Conecta y listo

    Detecta Docker Engine o Podman en el equipo y se conecta sin configurar el socket a mano. Ideal para desarrollo en portátil.

  • Avisos

    Notificaciones del sistema

    Avisa cuando un despliegue termina, un contenedor se cae o un servicio consume más de lo previsto, sin tener la ventana delante.

  • Segundo plano

    Siempre bajo vigilancia

    Puede arrancar con el sistema y mantener los stacks monitorizados con la ventana cerrada, igual que el modo web autoalojado.

  • Plataformas

    Linux, macOS y Windows

    Un mismo motor y una misma interfaz en los tres sistemas, con paquetes firmados y actualizaciones desde la propia aplicación.

  • Continuidad

    El mismo proyecto

    Los stacks creados en la web se abren en la app y viceversa. Elegir escritorio no supone renunciar al despliegue remoto ni al trabajo en equipo.
